# FinPilot — Mobile UI Design

## 1. Қолданылатын технологиялар

- Android Studio
- Java
- XML Layout
- Retrofit
- REST API
- JSON
- Laravel Sanctum

## 2. Мобильді қосымшаның экрандары

| Экран | Қызметі |
|---|---|
| Registration | Жаңа пайдаланушыны тіркеу |
| Login | Жүйеге кіру |
| Dashboard | Баланс, кіріс және шығыс |
| Add Income | Кіріс қосу |
| Add Expense | Шығыс қосу |
| History | Транзакциялар тарихы |
| Budget | Айлық бюджетті басқару |
| Statistics | Қаржылық статистика |

## 3. API интеграциясы

| HTTP әдісі | API маршруты | Қызметі |
|---|---|---|
| POST | /api/register | Тіркелу |
| POST | /api/login | Жүйеге кіру |
| POST | /api/logout | Жүйеден шығу |
| GET | /api/categories | Санаттарды алу |
| GET | /api/transactions | Транзакциялар тізімі |
| POST | /api/transactions | Транзакция қосу |
| GET | /api/transactions/{id} | Транзакцияны оқу |
| PUT | /api/transactions/{id} | Транзакцияны өзгерту |
| DELETE | /api/transactions/{id} | Транзакцияны жою |

## 4. Жүйенің байланысу құрылымы

Android Java → Retrofit → Laravel REST API → MySQL

Пайдаланушы жүйеге кірген кезде Laravel Sanctum токені алынады. Кейін қорғалған API сұраныстарына Bearer токені қосылады.

## 5. Интерфейс дизайны

- Ақ түсті фон.
- Жасыл түсті негізгі батырмалар.
- Қарапайым және түсінікті интерфейс.
- Төменгі навигация: Басты бет, Тарих, Бюджет, Статистика.

### Dashboard экран эскизі

- Жоғарғы бөлікте FinPilot логотипі.
- Total Balance карточкасы.
- Income және Expense карточкалары.
- Add Income және Add Expense батырмалары.
- Recent Transactions тізімі.
- Төменгі навигация.

### Login экран эскизі

- Email енгізу өрісі.
- Password енгізу өрісі.
- Login батырмасы.
- Register сілтемесі.

### Registration экран эскизі

- Name енгізу өрісі.
- Email енгізу өрісі.
- Password енгізу өрісі.
- Confirm Password өрісі.
- Register батырмасы.

### Add Income / Add Expense экрандары

- Amount енгізу.
- Category таңдау.
- Date таңдау.
- Description енгізу.
- Save батырмасы.

### History экран эскизі

- Транзакциялар тізімі.
- Кірістер жасыл түспен көрсетіледі.
- Шығыстар қызыл түспен көрсетіледі.
- Күн және санат көрсетіледі.

### Budget экран эскизі

- Айлық бюджет мөлшері.
- Қалған бюджет.
- Қолданылған бюджетті көрсететін Progress Bar.
- Санаттар бойынша бюджет.

### Statistics экран эскизі

- Кіріс және шығыс диаграммалары.
- Айлық статистика.
- Санаттар бойынша шығыс көрсеткіштері.

## 6. Дизайн шешімдері

- Material Design қағидалары.
- Ақ фон және жасыл акцент.
- Бірдей батырма стилі.
- Қолданушыға түсінікті навигация.
- Responsive Layout.
- Қаржылық ақпаратты карточкалар арқылы көрсету.
- API сұраныстары үшін Retrofit қолдану.
- Авторизация үшін Sanctum Bearer Token.

## 7. Қазіргі жағдай

Backend жүйесінде тіркелу, авторизация және транзакциялардың CRUD операциялары жүзеге асырылған. Мобильді интерфейсті жасау және Retrofit арқылы байланыстыру келесі кезеңде орындалады.

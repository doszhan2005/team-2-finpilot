# FinPilot — Жеке қаржыны басқару жүйесі

## 1. Жоба сипаттамасы

FinPilot — пайдаланушыларға жеке қаржысын тиімді басқаруға, кірістер мен шығыстарды бақылауға, бюджетті жоспарлауға және қаржылық жағдайын талдауға мүмкіндік беретін Android мобильді қосымшасы.

Қосымша пайдаланушылардың қаржылық операцияларын бір жүйеде сақтап, оларды ыңғайлы түрде басқаруға арналған.

## 2. Жобаның мақсаты

Заманауи бағдарламалау технологиялары мен бағдарламалық жобалау үлгілерін (Design Patterns) пайдалана отырып, жеке қаржыны басқаруға арналған толыққанды мобильді қосымша әзірлеу.

Жобаның негізгі мақсаты — қаржылық мәліметтерді қауіпсіз сақтау, кірістер мен шығыстарды есепке алу және пайдаланушыға өз қаржысын тиімді бақылауға көмектесу.

## 3. Қолданылатын технологиялар мен құралдар

- **Мобильді қосымша (Frontend):** Android Studio + Java — Android қосымшасының интерфейсі мен клиенттік логикасын әзірлеу.
- **Серверлік бөлік (Backend):** Laravel + PHP — серверлік логиканы жүзеге асыру және деректерді өңдеу.
- **Дерекқор:** MySQL — пайдаланушылар мен қаржылық операциялар туралы мәліметтерді сақтау.
- **API:** REST API — мобильді қосымша мен сервер арасындағы байланысты ұйымдастыру.
- **API-мен байланыс:** Retrofit — Android қосымшасынан серверге HTTP сұраныстарын жіберу және жауаптарды қабылдау.
- **Код редакторы:** Visual Studio Code (VS Code) — PHP және Laravel кодтарын жазу, өңдеу және жобамен жұмыс істеу.
- **Нұсқаларды басқару жүйесі:** Git және GitHub — бастапқы кодты сақтау, өзгерістерді бақылау және командалық жұмысты ұйымдастыру.

| Аружан | Team Lead / Architect |

**Команда мүшелерінің міндеттері:**

- **Backend Developer:** Laravel және PHP арқылы серверлік бөлікті, REST API мен дерекқормен байланысты әзірлеу.
- **Frontend / Mobile Developer:** Java және Android Studio арқылы мобильді қосымшаның интерфейсі мен функционалдығын әзірлеу.
- **QA & DevOps Engineer:** қосымшаны тестілеу, қателерді анықтау, GitHub арқылы код өзгерістерін бақылау және жобаның тұрақты жұмысын тексеру.

## 5. Негізгі функциялары

FinPilot мобильді қосымшасында келесі функциялар қарастырылған:

1. Пайдаланушыны тіркеу және жүйеге кіру.
2. Кірістерді қосу, өңдеу және жою.
3. Шығыстарды тіркеу және бақылау.
4. Айлық және жалпы бюджетті жоспарлау.
5. Қаржылық статистиканы көрсету.
6. Қаржылық операциялар тарихын сақтау.
7. Кірістер мен шығыстарды санаттарға бөлу.
8. Пайдаланушының қаржылық мәліметтерін басқару.

## 6. Жүйе архитектурасы

FinPilot жүйесі үш негізгі компоненттен тұрады:

- **Android мобильді қосымшасы (Java)** — пайдаланушы интерфейсі және клиенттік логика.
- **Laravel REST API (PHP)** — серверлік логика, деректерді өңдеу және API сұраныстарын басқару.
- **MySQL дерекқоры** — пайдаланушылардың қаржылық мәліметтерін сақтау.

Android мобильді қосымшасы Retrofit кітапханасы арқылы Laravel серверімен REST API көмегімен байланысады. Laravel PHP тілінде жұмыс істеп, MySQL дерекқорымен ақпарат алмасады.

Бағдарламалық кодты әзірлеу және өңдеу үшін Visual Studio Code қолданылады.

## 7. Design Patterns — Жобалау үлгілері

Жобада бағдарламалық архитектураны жақсарту, кодты қайта пайдалануды жеңілдету және жүйені кеңейту мақсатында алты жобалау үлгісі қолданылады:

### 1. Repository Pattern

Дерекқормен жұмыс істеуді бизнес-логикадан бөлу және мәліметтерге қол жеткізуді ұйымдастыру.

### 2. Adapter Pattern

Сыртқы API деректерін FinPilot жүйесінің ішкі форматына бейімдеу.

### 3. Strategy Pattern

Күндік, айлық және жылдық қаржылық есептеулердің әртүрлі алгоритмдерін қолдану.

### 4. Builder Pattern

Қаржылық есептерді бірнеше кезең арқылы құрастыру.

### 5. Memento Pattern

Қаржылық мәліметтердің алдыңғы күйін сақтау және қажет болған жағдайда қалпына келтіру.

### 6. Observer Pattern

Мәліметтер өзгерген кезде мобильді қосымша интерфейсінің автоматты түрде жаңартылуын қамтамасыз ету.

**Жобалау үлгілерінің топтары:**

- **Creational (құру үлгілері):** Builder.
- **Structural (құрылымдық үлгілер):** Repository, Adapter.
- **Behavioral (мінез-құлық үлгілері):** Strategy, Memento, Observer.

Аталған жобалау үлгілері FinPilot жүйесінің архитектурасын реттеуге, компоненттер арасындағы байланысты ұйымдастыруға және бағдарламалық кодтың сапасын арттыруға бағытталған.

## 8. Жобаны әзірлеу мерзімі

Жобаны әзірлеу мерзімі — 3 апта.

**Басталу күні:** 23 қараша 2026 жыл.

**Аяқталу күні:** 11 желтоқсан 2026 жыл.

**Жұмыс кезеңдері:**

- **1-апта:** талаптарды талдау, жүйе архитектурасын құру және жобаны жоспарлау.
- **2-апта:** мобильді қосымшаны, серверлік бөлікті және дерекқорды әзірлеу.
- **3-апта:** жобалау үлгілерін енгізу, тестілеу, қателерді түзету және құжаттаманы дайындау.

## 9. Құжаттама

Жоба құжаттамасына келесі материалдар кіреді:

- **SRS** — бағдарламалық жүйеге қойылатын талаптар құжаты.
- **ARCHITECTURE** — жүйе архитектурасының сипаттамасы.
- **PATTERNS** — жобада қолданылатын жобалау үлгілерінің сипаттамасы.
- **API Documentation** — серверлік API сұраныстары мен жауаптарының құжаттамасы.
- **USER GUIDE** — пайдаланушыға арналған қосымшаны пайдалану нұсқаулығы.

## 10. Командалық жұмыс тәртібі

Жобаны әзірлеу барысында Git және GitHub платформалары бастапқы кодты басқару және командалық жұмысты ұйымдастыру үшін қолданылады.

GitHub арқылы:

- Жобаның бастапқы коды сақталады.
- Команда мүшелерінің тапсырмалары бөлінеді.
- Өзгерістер Commit арқылы тіркеледі.
- Pull Request арқылы код өзгерістері ұсынылады.
- Code Review арқылы код тексеріледі.
- Issues арқылы қателер мен тапсырмалар бақыланады.

Әр команда мүшесі өзінің міндетіне сәйкес жұмыс істеп, дайын кодын GitHub репозиторийіне жүктейді. Команда мүшелері бір-бірінің жұмысын тексеріп, жобаны бірге жетілдіреді.

## Қорытынды

FinPilot жобасы жеке қаржыны басқаруды жеңілдетуге арналған мобильді жүйе болып табылады. Жобаны әзірлеу барысында Java, PHP, Laravel, MySQL, REST API, Retrofit, Git және GitHub технологиялары қолданылады.

Жоба нәтижесінде пайдаланушыларға кірістер мен шығыстарды бақылауға, бюджетті жоспарлауға және қаржылық жағдайын талдауға мүмкіндік беретін мобильді қосымша әзірлеу көзделеді.

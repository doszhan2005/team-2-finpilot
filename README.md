# FinPilot — Жеке қаржыны басқару жүйесі

## 1. Жоба сипаттамасы

FinPilot — пайдаланушыларға жеке қаржысын басқаруға, кірістер мен шығыстарды бақылауға және бюджетін жоспарлауға мүмкіндік беретін мобильді қосымша.

## 2. Жобаның мақсаты

Заманауи технологиялар мен бағдарламалық жобалау үлгілерін (Design Patterns) пайдалана отырып, жеке қаржыны басқаруға арналған толыққанды мобильді қосымша әзірлеу.

## 3. Қолданылатын технологиялар

- **Мобильді қосымша (Frontend):** Android Studio + Java
- **Серверлік бөлік (Backend):** Laravel + PHP
- **Дерекқор:** MySQL
- **API:** REST API
- **API-мен байланыс:** Retrofit
- **Нұсқаларды басқару жүйесі:** GitHub

## 5. Негізгі функциялары

- Пайдаланушыны тіркеу және жүйеге кіру
- Кірістерді басқару
- Шығыстарды бақылау
- Бюджетті жоспарлау және басқару
- Қаржылық статистиканы көрсету
- Қаржылық операциялар тарихын сақтау

## 6. Жүйе архитектурасы

Жүйе үш негізгі компоненттен тұрады:

- Android мобильді қосымшасы
- Laravel негізіндегі REST API сервері
- MySQL дерекқоры

## 7. Design Patterns — Жобалау үлгілері

Жобада үш негізгі топқа жататын кемінде бес жобалау үлгісі қолданылады:

- **Creational** — құру үлгілері
- **Structural** — құрылымдық үлгілер
- **Behavioral** — мінез-құлық үлгілері

## 8. Жобаны әзірлеу мерзімі

3 апта — 2026 жылғы 23 қарашадан 11 желтоқсанға дейін.

## 9. Құжаттама

Жоба құжаттамасына келесі материалдар кіреді:

- SRS — бағдарламалық талаптар құжаты
- ARCHITECTURE — жүйе архитектурасы
- PATTERNS — жобалау үлгілерінің сипаттамасы
- API Documentation — API құжаттамасы
- USER GUIDE — пайдаланушы нұсқаулығы

## 10. Командалық жұмыс тәртібі

Жобаны әзірлеу барысында GitHub платформасы бастапқы кодты басқару, тапсырмаларды бөлу, Pull Request жіберу, кодты тексеру және командалық жұмысты ұйымдастыру үшін қолданылады.
